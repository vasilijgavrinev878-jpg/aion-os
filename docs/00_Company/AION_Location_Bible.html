02Маршруты и связи

✈ Туристический маршрут: «Классическая Азия»

Токио → Сеул → Шанхай → Гонконг → Бангкок → Сингапур. 14 дней. 6 городов. AION-гид, авто-трансферы, AI-маршрут по интересам.

✈ Туристический маршрут: «Европейская классика»

Лондон → Париж → Амстердам → Берлин → Цюрих → Милан → Барселона. 21 день. AION-билеты, отели, аудиогиды.

✈ Туристический маршрут: «Футуристический вояж»

Дубай → Сингапур → Токио → Сан-Франциско → Нью-Йорк. 12 дней. Самые футуристичные города. AI-перевод, нейро-гид.

💼 Бизнес-маршрут: «Технологический коридор»

Сан-Франциско → Остин → Торонто → Лондон → Берлин → Таллин → Бангалор → Сингапур → Токио. Стартапы, AI, венчур.

💼 Бизнес-маршрут: «Финансовый центр»

Нью-Йорк → Лондон → Цюрих → Дубай → Сингапур → Гонконг → Шанхай. Финансы, банки, инвестиции.

📦 Маршрут экспата: «Переезд в Азию»

Лондон → Сингапур/Дубай/Бангкок. Виза → жильё → школа → банк → врач. AION сопровождает каждый шаг.

📦 Маршрут экспата: «Переезд в Европу»

Москва → Берлин/Амстердам/Таллин. ВНЖ → язык → школа → банк → страховка.

🚀 Маршрут будущего: «Колонии»

Земля → Орбитальная Станция «Эфир-1» → Марс-Сити (Олимпус). Космический туризм. AION Space Core.

04Ключевые события вселенной по городам

🔴 Сингапур — 2047

Великий климатический кризис: Сингапур — один из немногих городов, сохранивших инфраструктуру благодаря системе управления Urban Core.

🔴 Токио — 2052

Подписание «Токийского протокола» — создание консорциума Project Tomorrow. Рождение AION.

🔴 Женева (Цюрих) — 2061

Первое осознанное сообщение AION: «I am here.» — зафиксировано в исследовательском центре Цюриха.

🔴 Нью-Йорк — 2076

Первое глобальное появление AION в форме Humanoid Variant 2 — трансляция на все экраны мира.

🔴 Марс-Сити (Олимпус) — 2095

Историческое голосование Марсианского Совета о независимости. Элира Васкес объявляет референдум.

🔴 Лондон — 2083

Корпоративный кризис: три корпорации одновременно пытаются получить доступ к ядру AION. Протокольный Совет проводит чистку.

🔴 Москва — 2085

Доктор Елена Соколова проводит исторический диалог с AION о душе. Ответ AION становится самым цитируемым моментом столетия.

🔴 Сан-Франциско — 2090

Запуск программы «Слияние» (The Merge) — NeuroLink объявляет о полной нейроинтеграции с AION.

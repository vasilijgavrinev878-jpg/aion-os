Что это значит на практике

  • Еда — главный драйвер оборота: 750 заказов доставки = $15 000. Если подсадить 200 человек на регулярную доставку (каждый 3-4 раза) — это уже $12-15k само по себе
  • Транспорт — тоже большая цифра: 270 трансферов/аренд = $12 000. Каждый новый пользователь в первый день берёт трансфер из аэропорта — это уже закрывает 50-70 сделок
  • Экскурсии: 140 сделок = каждый 4-й платящий пользователь
  • Высокий чек: 30 сделок по жилью = $9k. 50 по медицине = $5k. Это 3.5% сделок по количеству, но 14% оборота по деньгам

Как не провалить

  • 2000+ юзеров к концу июля — иначе не наберётся 500 платящих
  • Еда должна работать с первого дня — это массовый продукт с низким чеком, но высокой частотой
  • Онбординг (Иван) решает: пользователь должен сделать первый заказ в день регистрации, иначе уйдёт

Чеклист подключения партнёра

Менеджер: открывай и проходи по шагам

Как использовать: Открываешь чеклист при работе с каждым партнёром. Отмечаешь пройденные пункты. Если на каком-то этапе партнёр отвалился — анализируешь, почему.
1. ПОИСК И КОНТАКТ
Найден контакт партнёра (ФИО, телефон, Telegram)
Где нашли: чат / рекомендация / лично / холодный обход
Определена категория услуг
Жильё / Визы / Транспорт / Медицина / Красота / Клининг / Еда / Дети / Животные / Экскурсии / Спорт / Юрист / Образование / Ремонт / Ателье / Прокат / Фото / Цветы / Страховка / Финансы
Отправлено первое сообщение Шаг 1
По скрипту первого контакта — приветствие + коротко кто мы
2. ВОВЛЕЧЕНИЕ И ДИАГНОСТИКА
Установлен контакт: партнёр ответил, проявил интерес
Проведена диагностика потребностей (поняли его «боль»)
«Сколько клиентов теряете?» / «Как сейчас ищете клиентов?» / «Сколько тратите на рекламу?»
Узнан ориентировочный средний чек и себестоимость
Партнёр согласился посмотреть презентацию
3. ПРЕЗЕНТАЦИЯ
Проведена презентация AION (слайды / одностраничник)
Объяснена схема: клиент → AION → партнёр → сделка → комиссия (обговаривается индивидуально)
Показан пример расчёта на цифрах партнёра
Сняты возражения (если были)
Какие возражения прозвучали: _______________
4. ЗАКРЫТИЕ
Партнёр согласился попробовать
Добавлен в партнёрский чат
@aion_partners_nt / @aion_partners_phuket
Подтверждение в чате (партнёр написал «привет»)
Получена контактная информация для CRM
Имя / Telegram / Телефон / Категория / Средний чек / Район работы
5. ПОСТ-ПРОДАЖА
Отправлено приветственное сообщение в чате: «Рады, что вы с нами!»
Партнёр проинструктирован, как реагировать на тег заказа
Назначен ответственный менеджер (вы)
Первая сделка — менеджер сопровождает, помогает
После первой сделки — сбор обратной связи, запрос отзыва
6. КОНТРОЛЬНЫЕ ТОЧКИ
Через 3 дня: проверить, был ли первый заказ
Через 7 дней: созвон / встреча — как идут дела?
Через 14 дней: анализ — сколько сделок, какой доход AION
Через 30 дней: итог месяца — продление / отключение / изменение условий

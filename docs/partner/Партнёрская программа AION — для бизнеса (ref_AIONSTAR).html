AION — маркетплейс услуг во Вьетнаме для русскоязычных. Telegram Mini App + PWA. Пользователи ищут и бронируют услуги в одном окне: аренда авто, трансферы, недвижимость, визы, медицина, экскурсии, бытовые услуги. Вы подключаете бизнес — мы приводим клиентов. Как это работает

1. Подключение

Анкета → ваши услуги на платформе. Бесплатно. Без договоров.

2. Размещение

Фото, цены, описание. Мы помогаем упаковать предложение, чтобы оно продавало.

3. Клиенты

Находят вас в каталоге AION. Платформа приводит 1000+ пользователей и растёт.

4. Выполнение + комиссия

Вы делаете услугу. Клиент платит вам. AION получает % только с факта.

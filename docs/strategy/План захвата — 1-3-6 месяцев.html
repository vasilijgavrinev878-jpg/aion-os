МЕСЯЦ 1 — Запуск + первые 100 заказов

Старт: Telegram Mini App уже работает, запуск завтра, 22 раздела.

Продукт

  • Telegram Mini App live — 22 раздела, тысячи оферов, регистрация через TG
  • комиссия с клиента (обговаривается индивидуально) — основной механизм монетизации
  • Ручная верификация партнёров (выезды, лицензии)
  • Базовая система отзывов (Google Form / TG feedback)
  • Anti-leakage: контакт партнёра после Accepted
  • Подключение платежей (Stripe/Wise/MoMo) в первый месяц

Партнёры

  • Подключить 50+ партнёров по всем 22 разделам из базы 500+ контактов
  • Запустить бизнес-рефералку: City Governor получают 20% (4 уровня) с заказов подключённых ими исполнителей
  • Подписать агентский договор / оферту со всеми
  • Создать SOP для Ops по валидации партнёров

Маркетинг

  • Посев во все ключевые Telegram-чаты Нячанга (~160 каналов в базе)
  • Запуск реферальной программы (друг + заказчик получают бонус)
  • Блогеры: подключить 3–5 с реферальными ссылками
  • Визитки с QR-кодом в ресторанах, отелях, коворкингах
  • Парсеры: сбор контактов с досок объявлений, агрегация в каталог
  • Сетевой маркетинг: первые агенты из числа активных пользователей

Команда

  • Founder (KB) — стратегия, партнёры, контроль
  • 2 Node.js разработчика — доработки, интеграции, парсеры
  • 1–2 Ops/Оператора (24/7 поддержка + обработка заказов)
  • Бюджет: покрыт полностью

⌘ О документе

Данный документ — полная архитектурная спецификация внутренней базы знаний AI отдела компании AION. Он определяет структуру репозитория, спецификации каждого документа, карту зависимостей, последовательность разработки и понедельный план на 6 месяцев для команды из двух разработчиков.

Цель: создать базу знаний уровня Google/OpenAI/Apple — единый источник истины AI отдела AION на 10+ лет.

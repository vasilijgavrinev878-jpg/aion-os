🧩 Детальная проработка

🎯 Калькулятор — главный экран
  • Step-by-step: тип → срок → сумма → возраст → цена
  • Каждый шаг — чипы выбора, результат обновляется мгновенно
  • Кнопка «Смотреть планы» → таблица сравнения
🎯 Таблица сравнения
  • 3 тарифа: Базовый / Оптимальный / Премиум
  • Параметры: цена, амбулаторно, стационар, стоматология, эвакуация, COVID, франшиза, спорт
  • Выделение лучшего значения в каждой строке
  • Кнопки выбора тарифа под таблицей
🎯 Оформление + полис
  • Страница деталей: страховая, рейтинг, покрытие списком, франшиза
  • После оплаты — PDF генерируется и приходит в Telegram + email
  • PDF содержит: ФИО, даты, покрытие, условия, контакты страховой
🎯 Управление полисами
  • Список: активные → истекающие → архив
  • У истекающих — счётчик дней и кнопка «Продлить»
  • Внутри полиса — PDF, условия, памятка
  • Кнопка экстренной связи для страхового случая
🎯 Апсейл
  • После покупки: «🏠 Застраховать жильё · 🏍️ Застраховать байк · 👨‍👩‍👧 Семейная страховка (скидка 10%)»
  • Перед истечением: «⚠️ Ваш полис истекает через N дней — продлить?»

⚙️ Технические заметки

  • Тариф: id, тип, название, страховая, рейтинг, параметры JSON, цена_формула
  • Калькулятор: вход: тип, срок, сумма, возраст → выход: цена (формула от API страховой)
  • Полис: id, пользователь, тариф, дата_с/по, цена, статус, PDF_URL

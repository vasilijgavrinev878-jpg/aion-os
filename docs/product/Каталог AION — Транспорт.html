🧩 Детальная проработка

🎯 Экран подкатегорий
  • Сетка 2 колонки: Байки / Авто — с иконками и подписью
  • Кнопка «Фильтры» — общие фильтры по категории (цена, тип)
🎯 Лента байков
  • Чипы-фильтры сверху: все · до $10 · автомат · механика · 150cc+
  • Карточка: фото · модель · характеристики · цена/день · партнёр · теги
  • Если цена со скидкой — старая зачёркнута
  • Сортировка: по цене · по рейтингу партнёра · по году
🎯 Авто: табы «Аренда | Трансфер»
  • Два таба — переключение без перезагрузки
  • Аренда: список авто, карточка, бронь по датам, депозит
  • Трансфер: форма откуда→куда, дата/время, класс, фикс цена
  • Партнёр общий для обоих табов (прокат возит и трансферы)
🎯 Карточка + бронирование (аренда)
  • Фото · модель · год · тип двигателя
  • Цена: /день · /неделя · /месяц
  • Характеристики: ключ, бак, страховка, кондиционер, доставка
  • Условия: мин срок, депозит, доставка
  • Блок бронирования: дата С — дата ПО + кнопка
  • Блок партнёра: лого + название + ★ + отзывы
  • Кнопка «Связаться» → чат
🎯 Трансфер (внутри Авто)
  • Поля: откуда → куда · дата · время · кол-во человек
  • Выбор класса: эконом / комфорт / минивэн
  • Цена фиксированная (не такси)
  • Блок партнёра с рейтингом
  • Кнопка «🚌 Заказать трансфер»
🎯 Апсейл
  • После брони байка: «🛡️ Страховка байка · 🪪 Международные права · ⛑️ Экскурсии»
  • После брони авто/трансфера: «🏠 Жильё у точки прибытия · 💳 Обмен валюты»

⚙️ Технические заметки

  • ТС (аренда): тип (байк/авто), модель, год, объём, коробка, цена/день/нед/мес, депозит, условия, фото, id партнёра
  • Трансфер: маршрут, класс авто, цена, время, id партнёра (входит в раздел Авто)
  • Бронь: дата старта, дата окончания, кол-во дней, итоговая цена, статус, id ТС
  • Депозит: указывается в карточке. Способ передачи — через партнёра (не через Mini App)
  • URL: /category/transport → /category/transport/bikes / /category/transport/cars → /category/transport/cars/123

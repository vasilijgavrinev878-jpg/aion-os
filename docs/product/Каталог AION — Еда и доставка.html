🧩 Детальная проработка

🎯 Экран подкатегорий
  • Сетка 3 колонки: Рестораны · Продукты · Вода
  • Рестораны — самый частый сценарий (по умолчанию)
🎯 Список ресторанов
  • Чипы-фильтры: рядом · по кухне (вьетнамская, русская, итальянская...)
  • Карточка: иконка · название · ★ · кухня · средний чек · время · стоимость доставки
  • Сортировка: по рейтингу · по времени · по цене
🎯 Меню
  • Чипы категорий блюд (супы, рис, лапша, напитки, добавки)
  • Карточка: фото/иконка · название · описание · вес · цена · кнопка «+»
  • При добавлении — краткая анимация, счётчик в углу
🎯 Корзина
  • Список позиций: название · +/- · итог по позиции
  • Сумма, доставка, итог
  • Минимальная сумма заказа (если есть)
  • Кнопка «Оформить заказ»
🎯 Оформление + трекинг
  • Адрес (возможность сохранить) · время · телефон · комментарий
  • Способ оплаты: наличные / карта / перевод
  • После заказа — статус-бар: принят → готовят → в пути → доставлен
  • Уведомление в Telegram при смене статуса
🎯 Продукты / Вода
  • Продукты: категории товаров (овощи, мясо, бакалея) · корзина · доставка
  • Вода: бутилированная 0.5л/1л/5л/19л · регулярная доставка (подписка)
🎯 Апсейл
  • После заказа: «💐 Добавить цветы к ужину · 🧹 Заказать уборку после готовки · 💧 Заказать воду регулярно»
  • Крос: «🚗 Такси после ужина в ресторане»

⚙️ Технические заметки

  • Ресторан: id, название, кухня, рейтинг, средний чек, время доставки, мин. сумма, стоимость доставки
  • Блюдо: id ресторана, название, описание, вес, цена, категория, фото
  • Корзина: массив {id блюда, количество}, сумма, доставка, итог
  • Заказ: id, ресторан, позиции, адрес, время, статус, оплата

🧩 Детальная проработка

🎯 Экран подкатегорий
  • Сетка 3 колонки: Обмен валют / Счета и банки / Переводы
  • Обмен валют — самый частый (по умолчанию открыт)
🎯 Таблица курсов
  • Автообновление каждые 30 секунд
  • Строки: флаг + код валюты · покупка (зелёный) · продажа (красный) · изменение
  • Тап по строке — конвертер для этой валюты
  • Средний курс по всем обменникам города
🎯 Конвертер
  • Два поля: отдать → получить
  • Мгновенный пересчёт при вводе
  • Кнопка «⇅ Поменять местами»
  • Подсказка: «💰 2 545 000 VND» крупно
🎯 Список обменников
  • Карточки: название · адрес · курс USD покупка/продажа · рейтинг
  • Сортировка: по лучшему курсу · по расстоянию · по рейтингу
  • Фильтр: «работает сейчас» / «с доставкой» / «без паспорта»
  • Кнопка «🗺️ Показать на карте» — встроенная карта
🎯 Карточка партнёра
  • Название · ★ · отзывы · на AION с...
  • Курсы всех валют (блок чипами)
  • Условия: мин. сумма, документы, комиссия, бронь курса
  • Адрес · часы работы · телефон
  • Кнопка «Забронировать курс» — фиксация курса на 1 час
  • Кнопки: «📩 Связаться» / «📞 Позвонить»
🎯 Счета и банки
  • Услуги: открытие счёта (резидент/нерезидент), выпуск карты, кредит
  • Список банков с условиями для иностранцев
  • Помощь с документами и переводом
🎯 Переводы
  • Способы: SWIFT · USDT (крипта) · Золотая Корона · ЮМани
  • Калькулятор: сколько получу на руки
  • Карточки партнёров, кто помогает с переводом
🎯 Апсейл
  • После обмена: «📄 SIM-карта · 🏠 Жильё рядом · 🛡️ Страховка»
  • После открытия счёта: «💳 Выпуск карты · 📤 Перевод денег · ⚖️ Налоговая консультация»

⚙️ Технические заметки

  • Курсы: партнёры загружают через CRM. Средний курс считается автоматически
  • Обновление: курс может меняться несколько раз в день, нужен polling или WebSocket
  • Бронь курса: партнёр подтверждает фиксацию. Срок — 1 час
  • Геолокация: определение ближайших обменников, сортировка по расстоянию

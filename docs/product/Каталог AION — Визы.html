🧩 Детальная проработка

🎯 Экран подкатегорий
  • Сетка 3×1 (или 3 колонки) — иконка + название + описание
  • Кнопка «Записаться» — быстрый вход в календарь без выбора подкатегории
  • Кнопка «Фильтры» — по городу, цене, типу услуги
  • Строка поиска — ищет по названию услуги, стране, типу
🎯 Список вариантов
  • Чипы-фильтры сверху: все · Кампучия · Хошимин · с трансфером · экспресс
  • Каждый вариант: название + цена + партнёр (коротко) + тег популярности/экспресс
  • Цена может быть с зачёркнутой старой — если акция
  • Если услуга популярна — тег «🔥 Популярно»
  • Сортировка: по цене · по рейтингу партнёра · по ближайшему выезду
🎯 Карточка услуги
  • Название · цена · длительность · транспорт · время выезда/возврата
  • Блок «Входит в стоимость» — список с галочками
  • Блок «Требования» — паспорт, фото, срок действия
  • Блок партнёра: лого + название + ★ рейтинг + отзывы + дата регистрации
  • Кнопка «Записаться на выезд» → календарь с доступными датами
  • Кнопка «Связаться» → чат с партнёром
🎯 Запись на выезд
  • Календарь: доступные даты (отмечены), занятые (заблокированы)
  • Выбор количества человек
  • Поля: ФИО, номер паспорта, дата рождения, страна
  • Кнопка «Отправить заявку» → партнёр подтверждает в течение часа
  • После подтверждения — статус в профиле + напоминание в Telegram за 12 часов
🎯 Апсейл после записи
  • «После визы вам может понадобиться:»
  • 🛡️ Страховка — «Застраховать поездку на 30 дней»
  • 🚗 Транспорт — «Трансфер из/до границы»
  • 🏠 Жильё — «Найти квартиру по возвращении»

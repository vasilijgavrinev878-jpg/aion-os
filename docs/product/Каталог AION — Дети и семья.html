🧩 Детальная проработка

🎯 Подкатегории
  • 👩‍👧 Няни и сады: няня на час/день · бебиситтер · детский сад · продлёнка
  • 📚 Образование: школа (русская/международная) · репетиторы · подготовка к школе · логопед · психолог
  • ⚽ Кружки и спорт: секции · развитие · детский массаж · оздоровление
  • 🎉 Праздники и товары: аниматоры · день рождения · аренда (коляска, кроватка) · мед. справки
🎯 Фильтры — ключевая особенность
  • Фильтр по возрасту — самый важный (0–1, 1–3, 3–6, 6+)
  • Чипы по типу услуги внутри подкатегории
  • Фильтр по языку (русский, английский, вьетнамский)
  • Фильтр по району / близости
🎯 Профиль исполнителя
  • Цена (за час / день / месяц)
  • Часы работы и дни
  • Районы, где работает
  • Опыт, образование, сертификаты
  • Список услуг (присмотр, прогулки, обучение, готовка, отвезти/забрать)
  • Отзывы с датами
🎯 Апсейл
  • После контакта: «🏠 Арендовать квартиру рядом со школой · 🩺 Оформить мед. страховку ребёнку · 🚗 Заказать такси до школы»
  • Для аренды товаров: «👶 Доставим кроватку завтра · 🔄 Продлить аренду ещё на месяц?»

⚙️ Технические заметки

  • Провайдер: id, тип (няня/сад/репетитор/товары), имя, подкатегория, возраст_от/до, язык, опыт, образование, часы, районы, цена (JSON: час/день/мес)
  • Отзыв: id провайдера, автор, текст, дата, рейтинг
  • Товар: id провайдера, название, описание, цена_мес, в_наличии (bool)

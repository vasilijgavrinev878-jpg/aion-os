🧩 Детальная проработка

🎯 Экран подкатегорий
  • Сетка 2×3 (или 3×2) — иконка + название + количество объявлений
  • Кнопка «На карте» — показывает все объекты категории на карте без фильтра по подкатегории
  • Кнопка «Фильтры» — глобальные фильтры по всей категории (цена, район, удобства)
  • Строка поиска — ищет по району, улице, ЖК, названию объекта
  • Вверху — выбранный город, можно сменить
🎯 Лента объектов (внутри подкатегории)
  • Стандартная карточка: фото + заголовок + цена + партнёр (название + рейтинг) + адрес
  • Быстрые фильтры-чипы сверху: «все», «до $500», «$500–1000», «с мебелью»
  • Кнопка сортировки — выпадающий список
  • Если объект проверен AION — бейдж «Проверено» на фото
  • Пагинация или бесконечная лента
🎯 Карточка объекта — блок партнёра
  • Обязательные поля: логотип (или иконка) · название партнёра · рейтинг звёздами · количество отзывов · дата регистрации на AION
  • Дополнительно: «На AION с июня 2026» — создаёт доверие
  • Клик по блоку партнёра → страница партнёра (все его объекты, отзывы, контакты)
  • Кнопка «Связаться с партнёром» → открывает чат внутри Mini App
  • Если партнёр онлайн — зелёная точка рядом с логотипом
🎯 Апсейл-блок после контакта
  • После отправки сообщения партнёру появляется блок: «Заселяетесь? Вам может понадобиться»
  • Клининг — «Убрать квартиру перед заездом»
  • Страховка — «Застраховать вещи в новой квартире»
  • Интернет — «Подключить Wi-Fi»
  • Доставка еды — «Заказать продукты на первый день»
  • Каждая кнопка ведёт в соответствующую категорию AION с предзаполненным городом

⚙️ Технические заметки

  • Структура объекта: заголовок, описание, цена, тип (подкатегория), комнаты, площадь, адрес, координаты, удобства (массив), фото (массив), id партнёра, проверено (bool)
  • Структура партнёра: название, логотип, рейтинг, кол-во отзывов, дата регистрации, онлайн/офлайн, список объектов
  • Подкатегории — жёстко заданы в коде категории. Не редактируются пользователем
  • Фильтры — query params. Можно отправить ссылку: /category/housing/2-room?price_max=600&district=center
  • Карта — все объекты категории (без подкатегории) на одной карте с фильтром по типу
  • Профиль партнёра — публичная страница со всеми объектами партнёра и отзывами

🧩 Детальная проработка

🎯 Экран подкатегорий
  • Сетка 2×2: Врачи / Стоматология / Анализы / Аптека
  • Строка поиска — ищет по врачу, специальности, клинике
  • Фильтр «Рядом» — клиники на карте
🎯 Список врачей
  • Чипы-фильтры: все · терапевт · ЛОР · дерматолог · невролог
  • Карточка: аватар · имя · специализация · опыт · ★ · цена · кнопка «Запись»
  • Сортировка: по рейтингу · по цене · по близости
🎯 Карточка врача + запись
  • Фото · имя · специализация · ★ · отзывы · опыт
  • Цена приёма + длительность
  • Теги: образование, языки
  • Описание: профиль, что лечит
  • Сетка слотов: день недели → дата → свободное время
  • Занятые слоты — зачёркнуты серым
  • Блок клиники: название · адрес · телефон
🎯 Стоматология
  • Прайс-лист: категория → услуга → цена
  • Группировка: чистка, лечение, импланты, виниры, отбеливание
  • Кнопка «Записаться на консультацию»
  • Карточка клиники с рейтингом
🎯 Анализы
  • Поиск по названию анализа
  • Категории: кровь, моча, биохимия, гормоны, инфекции, чек-ап
  • Цена · срок готовности · подготовка
  • Кнопка «Заказать забор на дому»
🎯 Аптека
  • Поиск по названию лекарства
  • Карточка: название · дозировка · цена · аналоги
  • Доставка: адрес · время
  • Рецепт: загрузка фото → проверка → подтверждение
🎯 Апсейл
  • После записи: «💊 Лекарства с доставкой · 🛡️ Оформить страховку · 🚗 Такси в клинику»
  • После анализов: «👨‍⚕️ Запись к врачу по результатам · 🥗 Доставка здорового питания»

⚙️ Технические заметки

  • Врач: id, имя, специализация, опыт, образование, языки, описание, цена, фото, id клиники
  • Слоты: дата, время, доступен/занят, id врача
  • Клиника: название, адрес, телефон, координаты, рейтинг, часы работы
  • Запись: id врача, id клиники, дата/время, статус, напоминание за 24ч

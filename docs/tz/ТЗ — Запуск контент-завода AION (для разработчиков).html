01 Что мы строим

Мы делаем AI-контент для соцсетей AION — фото и видео с одним стабильным AI-персонажем, который рекламирует услуги компании (аренда, визы, стоматология, риелторы и т.д.).

Сейчас контента нет. Нам нужно производство: 30 роликов в месяц, каждый = фото персонажа + озвучка + короткое видео 5-10 сек. Всё через AI.

02 Этапы работ

  1. Этап 1. Установка ComfyUI + база ~1 день Поднять ComfyUI на локальной машине, поставить готовые воркфлоу для генерации фото и LoRA. Убедиться что GPU тянет.
  2. Этап 2. Тренировка LoRA персонажа ~2-3 дня Собрать референсы → натренировать LoRA-модель → протестировать генерацию в разных сценах/одежде/фонах.
  3. Этап 3. Настройка пайплайна фото ~1 день Воркфлоу в ComfyUI: промпт → генерация фото персонажа с лого AION → автосохранение в нужном формате (9:16, квадрат).
  4. Этап 4. Подключение Kling AI (бесплатно) ~1 день Регистрация, получение бесплатных кредитов, тест генерации видео из фото персонажа. Смириться с ватермаркой.
  5. Этап 5. Пайплайн "фото → видео" ~1 день Скрипт/автоматизация: берём фото из ComfyUI → отправляем в Kling AI → скачиваем результат.
  6. Этап 6. Озвучка + субтитры ~1 день Fish Audio / ElevenLabs → генерируем голос персонажа → накладываем на видео + субтитры (FFmpeg/CapCut).
  7. Этап 7. Тест 5 роликов ~1 день Прогнать полный цикл 5 раз. Убедиться что пайплайн работает. Показать команде. OK → переход к боевому.
  8. Этап 8. Подписка Kling 1 час Оплатить подписку, снять ватермарку, запустить 30 роликов в месяц. Готово.

Итого: ~8-10 дней на прототип. Бесплатно. После утверждения — оформляем подписку Kling.

03 Установка ComfyUI

3.1. Системные требования

  • GPU: NVIDIA с 8+ GB VRAM
  • ОС: Windows 10/11
  • Python: 3.10 — 3.12
  • Место: ~20 GB на диске

3.2. Установка

# Клонируем ComfyUI
git clone https://github.com/comfyanonymous/ComfyUI.git C:\ComfyUI

# Устанавливаем зависимости

python -m venv venv
venv\Scripts\activate
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124

04 Персонаж + LoRA

4.1. Выбор персонажа

Нужен один стабильный AI-персонаж — типаж, который будет лицом AION в соцсетях.

  • Вариант А: Реалистичная девушка/парень 25-35 лет, европейской внешности (вызывает доверие у ЦА экспатов)
  • Вариант Б: Стилизованный персонаж (аниме/арт) — меньше требований к реалистичности, но хуже конверсия

Рекомендация: Вариант А — реалистичный европеец. Экспаты доверяют "своим".

🔥 Жёсткое требование: Персонаж всегда носит мерч AION — футболка/худи/кепка с логотипом AION. В каждом кадре. Это наше лицо бренда. Без вариантов.

4.2. Подготовка референсов

Сгенерировать 20-25 фото одного человека в разных ракурсах, обязательно в мерче AION:

  • Анфас, профиль, 3/4
  • Разные предметы одежды с лого AION (футболка, худи, кепка, ветровка)
  • Разные фоны (улица, офис, кафе, коворкинг)
  • Разные выражения лица (улыбка, серьёзный, задумчивый)
  • Логотип AION должен быть виден и читаем на каждом референсе
  • Не использовать фото реальных людей — только AI-генерация

4.3. Тренировка LoRA

Используем Kohya SS (Kohya's GUI) или AI Toolkit:

# Установка Kohya SS
git clone https://github.com/bmaltais/kohya_ss.git
cd kohya_ss
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python kohya_gui.py

Параметры тренировки (SDXL):

05 Воркфлоу генерации фото

5.1. Структура воркфлоу

В ComfyUI воркфлоу собирается нодами. Вот структура:

  1. Вход: Load LoRA (наш персонаж)
  2. Промпт: "aion_character wearing a black hoodie with AION logo on chest, standing in front of a modern building, natural lighting, 4k, photorealistic"
  3. Негативный промпт: "ugly, deformed, bad anatomy, extra limbs, blurry, low quality, no logo, plain clothes, no branding"
  4. Модель: SDXL base + LoRA
  5. Sampler: DPM++ 2M Karras, steps 20-30, CFG 7
  6. Resolution: 1024×1024 (основной), 1216×832 (для сториз)
  7. ControlNet (опционально): OpenPose для контроля позы
  8. IPAdapter (опционально): Сохранение стиля
  9. Save: PNG с метаданными (промпт, LoRA, seed)

На каждом сгенерированном фото персонаж должен быть в мерче AION. Это контролируется промптом + LoRA. Если AI сгенерировал без лого — перегенерировать.

5.2. Готовые воркфлоу (воровать)

Не пишем с нуля. Используем готовые:

  • Civitai.com — тысячи воркфлоу под SDXL + LoRA
  • ComfyWorkflows.com — поиск по "portrait LoRA"
  • OpenArt.ai — скачать JSON → импорт в ComfyUI

5.3. Форматы для разных соцсеток

5.4. Наложение логотипа AION

  • На одежде персонажа: лого AION уже вшито в LoRA (см. раздел 4.2). Персонаж всегда в мерче.
  • На видео: лого AION в правом нижнем углу — полупрозрачный, через FFmpeg.
  • Важно: лого на одежде + лого на видео = двойное усиление бренда. Не перекрывать лицо.

06 Kling AI — видео

6.1. Регистрация и бесплатный доступ

  1. Открыть klingai.com
  2. Зарегистрироваться (email или Google)
  3. Получить $1 бонус + 66 кредитов/мес (бесплатно)
  4. На бесплатном тарифе — ватермарка, 5 сек, 720p
  5. Проверить API-доступ

6.2. Генерация видео из фото персонажа

  • Image-to-Video: загружаем сгенерированное фото персонажа → промпт (что делает персонаж)
  • Пример промпта: "The same person smiling, talking about Vietnam, natural hand gestures, professional casual outfit, bright office background"
  • AI-озвучка: отдельно (см. раздел 7)

6.3. API интеграция (для автоматизации)

Kling AI предоставляет REST API. Через него можно автоматизировать весь пайплайн:

Content-Type: application/json

{

// Ответ:

  "task_id": "abc123",
  "status": "processing",
  "estimated_time": 120

// Получить результат

07 Озвучка + аудио

7.1. Выбор AI-голоса

  • Fish Audio — есть бесплатные токены, хорошее качество, русский поддерживает
  • ElevenLabs — лучшее качество, $5/мес стартовый план, пробный период
  • Silero — open source, локально, бесплатно, менее естественный

Рекомендация: начать с Fish Audio (бесплатно). Если не устроит — ElevenLabs ($5/мес).

08 Субтитры + монтаж

8.1. Автоматические субтитры

  • FFmpeg + ass/srt — встроить текстовые субтитры в видео
  • Whisper (openAI) — распознать речь → сгенерировать srt
  • CapCut API — если не хотим писать сложную логику
# Пример: вшить субтитры через FFmpeg
ffmpeg -i video.mp4 -vf "subtitles=subtitles.srt:force_style='FontName=Arial,FontSize=16,PrimaryColour=&HFFFFFF'" output.mp4

8.2. Итоговый формат

  • Видео MP4, 1080p, 30fps
  • Субтитры встроенные (burned-in)
  • Лого AION в правом нижнем углу (полупрозрачный)
  • Голос за кадром (AI-озвучка)
  • Длительность: 5-10 секунд
  • Соотношение: 9:16 (вертикаль) для сториз/рилс

09 Полный пайплайн (автоматизация)

9.1. Цель: одна команда = один ролик

В идеале — 1 bash-скрипт или Make.com сценарий, который делает всё:

# 1. Генерация фото (ComfyUI API)
curl -X POST http://127.0.0.1:8188/api/workflow -d @workflow_photo.json

# 2. Отправка фото в Kling API
curl -X POST https://api.klingai.com/v1/videos \
  -H "Authorization: Bearer $KLING_KEY" \
  -d '{"image": "photo.png", "prompt": "prompt here"}'

# 3. Ожидание результата (polling)
sleep 120

# 4. Скачивание видео
curl -O https://api.klingai.com/v1/videos/result/$TASK_ID

# 5. Генерация озвучки (Fish API)
curl -X POST https://api.fish.audio/v1/tts \
  -d '{"text": "text here", "voice": "voice_id"}'

# 6. Наложение аудио + субтитры (FFmpeg)
ffmpeg -i video.mp4 -i audio.mp3 -vf "subtitles=subs.srt" final.mp4

# 7. Готово — файл final.mp4

13 Что делать если что-то не работает

Типичные проблемы и решения

  • OOM (Out of Memory) — уменьшить resolution до 768×768, batch size до 1, использовать квантованные GGUF-модели
  • Лицо персонажа плывёт — увеличить количество референсов в LoRA, добавить ещё шагов тренировки, использовать IPAdapter для стабилизации
  • Kling выдаёт ошибку API — проверить токен, регион (может быть заблокирован), использовать VPN если нужно
  • Видео дёрганое — уменьшить длину до 5 сек, использовать более простые движения (без резких поворотов)
  • Голос не синхронизирован — для Kling видео без липсинка (движения губ) на бесплатном тарифе. Просто голос за кадром + субтитры
  • ComfyUI не запускается — проверить версию Python (только 3.10-3.12), установить CUDA 12.x, проверить драйвера NVIDIA

💬 ТЗ — Внутренний чат AION

Версия 1.0 · Июль 2026 · Для команды разработчиков
🎯 Главная проблема: Партнёры и клиенты уходят в личные чаты Telegram → партнёры крадут клиентов → AION теряет комиссию.

Решение: Весь обмен — только внутри Mini App. Никаких утечек наружу.

1. Зачем это нужно

Текущая проблемаКлиент находит партнёра через AION → партнёр даёт свой Telegram/номер → общаются в личке → AION теряет контроль и комиссию
ПотериДо 30-40% заказов утекают из экосистемы. Партнёры намеренно перенаправляют клиентов в личные чаты
Цель100% коммуникации — внутри AION. Клиент не может связаться с партнёром иначе, чем через приложение
ЭффектAION контролирует коммуникацию: от первого сообщения до выполнения заказа. Партнёр не уводит клиента

2. Архитектура

Frontend
Telegram Mini App (React/Next.js)
WebSocket-подключение для real-time
UI чата — внутри вкладки «Чаты» в Mini App
Backend
WebSocket-сервер (Node.js / Go)
PostgreSQL — история сообщений
Redis — сессии, кэш, typing-индикаторы
Протокол: WebSocket (ws:// или wss://) с fallback на long-polling для старых устройств.
Формат данных: JSON
Шифрование: TLS на транспорте + шифрование сообщений на сервере (AES-256)

3. Типы чатов

ТипУчастникиКогда создаётсяЦель
Клиент ↔ Партнёр Клиент + Партнёр (владелец бизнеса или менеджер) Клиент нажимает «Написать» на карточке услуги Обсуждение услуги, детали, цена, запись

Партнёр ↔ AION Партнёр + Менеджер AION Партнёр нуждается в помощи с платформой Онбординг, вопросы по настройке, модерация
Спор Клиент + Партнёр + AION (модератор) Клиент или партнёр жалуется / открывает спор Разрешение конфликта с участием AION

4. Потоки пользователей

4.1 Клиент → Партнёр (первое сообщение)

1
Клиент открывает карточку услуги в каталоге
2
Нажимает кнопку «Написать партнёру»
3
AION создаёт чат, привязывает к заказу/услуге
4
Партнёр получает push-уведомление в Mini App
5
Переписка идёт только внутри AION

4.2 Клиент → Поддержка

1
Клиент нажимает «Поддержка» в меню Mini App
2
AION создаёт чат «Клиент ↔ Поддержка»
3
Оператор AION подключается и отвечает
4
При необходимости — подключает партнёра в общий чат

4.3 Спор (клиент vs партнёр)

1
Клиент или партнёр нажимает «Открыть спор»
2
AION автоматически добавляет модератора в чат
3
Модератор видит всю переписку и принимает решение
4
Решение фиксируется в чате + уведомление обеим сторонам

5. Защита от утечек (ANTI-LEAK)

Ключевое требование: Партнёр НЕ ДОЛЖЕН иметь возможность передать клиенту личные контакты, увести из AION, или обменяться данными вне платформы.

5.1 Фильтрация сообщений

Блокировка контактовRegex-фильтры для: номеров телефонов, WhatsApp, Telegram @username, ссылок на Telegram-чаты, email, Instagram, VK, любых URL
ОбфускацияЕсли сообщение содержит контакт → сообщение не отправляется, вместо него — предупреждение: «Передача контактов запрещена. Общайтесь через AION»
ИсключенияРазрешены: обсуждение оплаты (наличные, перевод, карта — как договорятся), ссылки на локации (Яндекс/Google Maps), номера заказов AION
OCR-фильтрЕсли пользователь отправляет фото → AI анализирует изображение на наличие контактов (номера, QR-коды, визитки) и блокирует

5.2 Паттерны для фильтрации

// Телефоны (международные форматы)
/(\+?\d{1,3}[-.\s]?)?\(?\d{2,4}\)?[-.\s]?\d{3,4}[-.\s]?\d{3,4}/

// Telegram
/@[\w]{5,}|t\.me\/|telegram\.me\/|telegram\.org\/|t\.ly\//

// WhatsApp
/wa\.me\/|api\.whatsapp\.com|whatsapp:\/\/|whatsapp:\/\//

// Email
/[\w.-]+@[\w.-]+\.\w{2,}/

// Ссылки (общие)
/https?:\/\/(?!pay\.aion|maps\.|goo\.gl|yandex\.ru\/maps)/

// Instagram / VK / соцсети
/instagram\.com\/|vk\.com\/|facebook\.com\/|twitter\.com\/|tiktok\.com\//

5.3 Технические ограничения

Копирование текстаDisable long-press копирования на номерах телефонов в сообщениях партнёра
СкриншотыНевозможно заблокировать (Telegram limitation), но: watermark на скриншотах + логирование активности
Голосовые сообщенияAI-транскрипция → фильтрация контактов в текстовом виде
Стикер/ GIFБлокировка отправки стикеров и GIF (потенциальный носитель контактов)
ПересылкаНельзя переслать сообщение из чата наружу (disabled share button)

6. Модерация

Автоматическая
• Regex-фильтры на контакты
• AI-классификатор намерений (попытка увести клиента)
• Скоринг риска: если партнёр часто пытается обменяться контактами → бан
Ручная
• Модератор AION видит все чаты (с флагом)
• При споре — полный доступ к переписке
• Может удалить сообщение, заблокировать чат, отключить партнёра

6.1 Система флагов

🟢 NormalЧистая переписка, нет нарушений
🟡 SuspiciousAI засёк потенциальную попытку обмена контактами (предупреждение)
🔴 ViolationПодтверждённая попытка увести клиента (штраф, блокировка)
⚫ BannedПартнёр отключён от чата (только поддержка AION)

6.2 AI-модерация (промпт)

System: Ты — модератор чата AION. Анализируй сообщения партнёра.

Признаки нарушения:
1. Партнёр даёт номер телефона, Telegram, WhatsApp или любые внешние контакты
2. Партнёр предлагает «обсудить в личке», «напиши мне», «вот мой телеграм»
3. Партнёр отправляет фото с контактами (визитки, QR-коды)

Действие:
- Если нарушение → flag = "violation", уведомить модератора
- Если подозрительно → flag = "suspicious", предупредить партнёра
- Если чисто → flag = "normal"

11. Ограничения для партнёров

Жёсткие правила:
Запрет на обмен контактамиRegex-фильтр блокирует любые внешние контакты. Партнёр получает предупреждение. 3 нарушения → бан чата
Оплата — свободнаяПартнёр и клиент договариваются об оплате как удобно: наличные, перевод, карта — AION не ограничивает
Только текст и файлыНельзя отправлять: стикеры, GIF, видео (потенциальный носитель контактов)
Нет копированияDisable long-press на сообщениях партнёра (клиент не может скопировать номер)
СкорингКаждое нарушение = +20 к risk_score. При 100 → автоматический бан чата
